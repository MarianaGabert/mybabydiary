Medidor de Pressão Bluetooth

Compatível com dispositivos BLE como Omron HEM-7144T2

Como funciona: Este app usa a Web Bluetooth API para se conectar a um medidor de pressão arterial BLE. Os valores são lidos da característica 0x2A35 (Blood Pressure Measurement) do serviço 0x1810 (Blood Pressure). Os dados são decodificados no formato SFLOAT definido pelo Bluetooth SIG.
